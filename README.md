Практична робота № 3

Тема: Узагальнення, декоратори та утиліти типів TypeScript

Варіант 10: Зоотовари (PetSupplyEntity).

Мета роботи

Опанувати узагальнення (generics), утилітарні типи TypeScript, принципи побудови узагальненого репозиторію та універсальної API-відповіді.

Використані технології

TypeScript

Node.js

npm

tsx

Git та GitHub

Реалізований функціонал

Створено базовий інтерфейс BaseEntity.

Створено узагальнений інтерфейс IRepository<T>.

Реалізовано InMemoryRepository<T> для роботи з даними в пам’яті.

Створено сутність PetSupplyEntity з полями назви, ціни, категорії тварин і ваги упаковки.

Реалізовано створення товарів, пошук за ID, отримання списку та видалення.

Створено узагальнений тип ApiResponse<TData>.

Запуск проєкту

Встановити залежності:

npm install

Запустити програму:

npm run dev

Перевірити компіляцію:

npm run build

Результат

Програма успішно запускається, демонструє роботу зоотоварів у пам’яті, пошук за ідентифікатором і видалення запису.
